# 🚩 비즈니스 룰

## 기능 요구사항

- e.g. 도서는 하나 이상의 카테고리에 속할 수 있다.

## 주요 용어 정의
[유비쿼터스 언어사전 참조](ubiquitous-language.md)

| 용어 | 정의 |
|------|------|
| 도서(마스터) | 지은이, 제목 등 기본 정보를 가진 도서의 기준 정보 |
| 보유도서 | 실제 도서관이 소장하고 있는 물리적 도서 (도서마스터의 실제 책) |
| 카테고리 | 도서를 분류하는 기준 (예: 소설, 역사, 과학 등) |
| 도서상태 | 보유도서의 현재 상태 (대여가능, 대여중, 훼손, 분실, 수선중) |
| 지은이 | 도서를 저술한 작가 |

## 비즈니스 룰

### BR-001: 신규 도서 카테고리 필수
**조건**: 신규 도서(마스터)를 등록할 때  
**규칙**: 반드시 1개 이상의 카테고리를 지정해야 한다  
**예외**: 카테고리 미지정 시 등록 불가, 동일한 카테고리를 2개 이상 지정할 수 없음

---

### BR-002: 도서 다중 카테고리 허용
**조건**: 도서(마스터) 등록 및 수정 시  
**규칙**: 하나의 도서는 여러 카테고리에 속할 수 있다  
**예외**: 없음

```
예시: "컴퓨터 과학 개론" → [컴퓨터, 교육, 기술] 카테고리 동시 지정 가능
```
