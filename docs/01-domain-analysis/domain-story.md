# 도메인 스토리

### 신규 도서 등록

- 관리자는 제목,지은이,카테고리를 입력 후 도서정보를 시스템에 등록한다.
    - 이때 시스템에 등록한 도서정보가 도서(마스터)가 된다.
- 실제로 보유한 도서가 있는 경우 보유도서를 등록한다.
    - 바코드번호를 발급하고, 등록한 도서(마스터)를 선택하여 보유도서를 시스템에 등록한다.
        - 이때 시스템이 보유도서의 도서상태를 대여가능 상태로 등록한다.

### 카테고리별 도서 검색

- 카테고리를 선택 후 도서를 검색 한다.
    - 대여가능한 수량과 전체 보유 수량을 함께 표기한다. (예: 대여가능 2권 / 전체 5권)
    - 대여가능한 도서를 우선으로 정렬하여 표시한다.

### 지은이/제목으로 도서 검색

- 지은이, 제목 어느 타입으로 검색할 지 선택한다.
- 검색 키워드를 입력 후 도서를 검색한다
    - 대여가능한 수량과 전체 보유 수량을 함께 표기한다. (예: 대여가능 2권 / 전체 5권)
    - 대여가능한 도서를 우선으로 정렬하여 표시한다.

### 특정도서 카테고리 변경

- 변경할 도서를 선택한다.
- 도서의 현재 카테고리 목록을 확인한다.
- 카테고리를 추가, 수정, 삭제한다.
  **카테고리 추가**
    - 추가할 카테고리를 선택한다.
    - 도서에 이미 속한 카테고리 선택 시 추가불가를 안내한다.

  **카테고리 수정:**
    - 도서에 설정할 카테고리를 선택한다. (기존 카테고리 포함)
    - 동일한 카테고리 2개 이상 중복 선택 시 변경불가를 안내한다.

  **카테고리 삭제:**
    - 삭제할 카테고리를 선택한다.
    - 도서가 속한 카테고리가 유일한 카테고리(1개만 가질 때) 삭제불가를 안내한다.

### 도서(마스터) 삭제
- 관리자는 삭제할 도서(마스터)를 선택한다.
- 시스템은 해당 도서의 모든 보유도서 정보를 확인한다.
- 삭제 확인 후 도서(마스터)와 관련된 모든 보유도서를 함께 삭제한다.
    - 대여중인 보유도서가 있으면 삭제불가를 안내한다.

### 도서 상태 변경

- 관리자는 상태를 변경할 보유도서를 선택한다.
- 현재 상태를 확인하고 변경할 상태를 선택한다.
- 시스템은 상태 전이 규칙을 검증한다.
    - 훼손/분실/수선중 → 대여중 변경 시 변경불가를 안내한다.
    - 대여중 -> 훼손/수선중/대여가능 변경 시 반납처리 필요 안내한다.
    - 검증 통과 시 도서 상태를 변경한다.

### 도서 반납 처리
- 관리자는 반납할 보유도서의 바코드번호를 스캔한다.
- 시스템은 해당 도서가 대여중 상태인지 확인한다.
- 반납 처리 후 도서상태를 선택한다.
    - 정상: 대여가능 상태로 변경
    - 손상 발견: 훼손 또는 수선중 상태로 변경


### 도서 정보 수정

- 관리자는 정보 수정할 도서를 선택한다.
- 수정할 지은이, 제목을 입력한다.
- 시스템은 BR-006 규칙을 검증한다. (지은이, 제목 필수)
- 검증 통과 시 도서 정보를 수정한다.
