# 📚 도서관 도메인 모델

## 🏗️ 도메인 엔티티

### 1. 도서 (Book)
**설명**: 도서의 기본 정보를 관리하는 기준 데이터

| 속성명 | 타입 | 필수 | 설명 |
|--------|------|------|------|
| bookId | Long | Y | 도서 고유 식별자 |
| title | String | Y | 도서 제목 |
| authorId | Long | Y | 지은이 ID (외래키) |

**관계**:
- Author (N:1) - 하나의 도서는 하나의 지은이를 가짐
- BookCategory (1:N) - 하나의 도서는 여러 카테고리에 속할 수 있음
- OwnedBook (1:N) - 하나의 도서는 여러 보유도서를 가질 수 있음

---

### 2. 지은이 (Author)
**설명**: 도서의 저자 정보를 관리

| 속성명 | 타입 | 필수 | 설명 |
|--------|------|------|------|
| authorId | Long | Y | 지은이 고유 식별자 |
| authorName | String | Y | 저자명 |

**관계**:
- Book (1:N) - 하나의 지은이는 여러 도서를 쓸 수 있음
